# TradeJourney API

Backend API for the TradeJourney trading journal platform.

## Tech Stack

- Node.js
- Express
- TypeScript
- MySQL
- JWT Authentication
- bcrypt

## Features

- User Registration
- User Login
- JWT Authentication
- Refresh Tokens
- Protected Routes

## Development

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build:

```bash
npm run build
```

Start production:

```bash
npm start
```
